# Data sources and validity

Airport-scene reference: **2026-11-13, Asia/Taipei (UTC+8)**. This is a research-backed entertainment simulation, not an operational airport database. AIRAC 05/26 (effective **2026-10-29**) has been checked for runway data, listed stand positions, taxiway pavement specifications, markings, and lighting. Terminal interiors now include selected public-area layouts and documented lounge themes, but the terminal shells, interior dimensions, furniture locations, stand lead-ins and chart-based taxi graph remain simplified visual interpretations; no BIM/CAD terminal plans or live NOTAM feed are available. A separate official flight-board snapshot is documented below.

## Official Taoyuan flight snapshot

The game also contains a fixed snapshot of the Taoyuan International Airport Corporation's [Taoyuan International Airport real-time flights dataset](https://data.gov.tw/en/datasets/26194), captured **2026-11-11 at 10:51:07 Asia/Taipei** from its [CSV resource](https://odp.taoyuan-airport.com/dataset/2023081816?format=csv). The source metadata lists five-minute updates and the **Open Government Data License, version 1.0**. The snapshot contains **1,208 records** (611 arrivals and 597 departures) from **62 IATA carrier codes**. It preserves the published flight number, direction, destination/origin, scheduled and expected times, terminal, gate, status, and reported aircraft model. The source lists 636 aircraft models and leaves 572 blank.

The archived snapshot is used only when the scenario date is **2026-11-11**. Other dates continue to use the explicitly labeled deterministic synthetic schedule. There is no runtime network request. When the official feed has no aircraft model, the simulator uses an A320-size proxy so the flight remains controllable; a published model is displayed as reported, while the nearest existing family profile drives simulation geometry and movement. The 777-family proxy is used for the two A380-861 records. A reported gate is preserved; where the scene's stand set or capacity cannot match it, the simulator uses a compatible stand and shows that mapping. The snapshot does not provide a certified runway assignment, taxi clearance, or aircraft track, so those operations remain simulated. The four existing custom liveries remain bespoke original approximations, and the 58 added carriers now have their own procedural standard-paint interpretations; they are not exact aircraft paint kits. Existing carriers have configured radio telephony names; for new carriers, spoken radio falls back to spelling the IATA code because the official telephony designators have not yet been verified.

Attribution: **Taoyuan International Airport Corporation Ltd., “Taoyuan International Airport real-time flights,” snapshot 2026-11-11 10:51:07 (Asia/Taipei).** Reuse is under the [Open Government Data License, version 1.0](https://data.gov.tw/en/license). The portal describes the live dataset as updated every five minutes; this bundled file is a static dated snapshot, not a live feed.

Landside and apron outlines use **© OpenStreetMap contributors**, available under the [Open Database License](https://www.openstreetmap.org/copyright). The game's always-visible attribution links to that page; the derived, anonymized feature/node dataset and provenance manifest are available locally at `assets/geography/taoyuan-osm-source.json` and `assets/geography/taoyuan-osm-manifest.json`. No contributor names or account data are retained. The runtime subset contains 454 road ways, 17 apron ways and 29 parking ways before render-time exclusions. The airport's existing aircraft graph is unchanged.

The data were retrieved on **2026-10-28** from the public [OSM API](https://api.openstreetmap.org/) in 12 tiles covering latitude 25.055–25.115 and longitude 121.195–121.275. Only ways whose latest current version and all referenced current node versions were last edited no later than **2026-09-06 04:00 UTC** were retained. This is an intentionally **incomplete subset of unchanged current objects**, not a historical snapshot: deleted objects and objects subsequently edited cannot be recovered by this filter. Consequently it does not prove every rendered feature existed exactly in the game scenario and omissions are expected. The importer `scripts/import-osm-airport.py` records tile checksums and projects the coordinates using the same local basis as the airport model. Public surface motor roads are shown; mapped underground/covered ways are omitted, and road strips are clipped near the simulator's runway and taxi corridors because the operational graph and building shapes are approximate. Road widths without reliable OSM width/lanes are visual defaults. Parking outlines are surface representations, not surveyed parking bays. The surrounding fields and buildings remain generalized scenery. Roads are visual only and do not change aircraft collision or taxi-routing logic.
# Northwest coastal scenery (visual only)

Major roads, rivers and settlement centres come from © OpenStreetMap contributors, [ODbL](https://www.openstreetmap.org/copyright), using an Overpass snapshot dated 2026-06-01 08:52:28 UTC. The city buildings are procedurally distributed near mapped settlement centres, and fields and vegetation are invented scenery rather than aerial imagery or surveyed land use. Coastline, road alignment, buildings, trees, weather, seasonal changes and heights may differ from the real landscape.
